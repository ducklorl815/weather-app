# Google Session: Credential Path Probe + Reconnect without delete

Users often see a full login screen after relaunch, while also switching between packaged LifeTour and `npm start` (separate userData trees). Phase-1 auth止血 therefore adds Credential Path Probe (show active path; details collapsed by default; if active has no Credential and a known alternate does, auto-copy into active and note it in diagnostics) and changes Reconnect so `AUTH_REVOKED` prefers OAuth / Full Login **without** deleting `google_token.json`; Logout remains the explicit clear+relaunch fallback. We rejected “Logout as the default reconnect action” and “force a single shared userData root for dev and install” because the first recreates empty-Credential logins and the second couples environments too tightly.
