開機時自動啟動
彈跳訊息提醒

開啟後，私人密語或群組 @你 會跳出置頂訊息框（最小化時也會顯示）。點訊息框可開啟回覆。關閉則完全不彈。

按 ✕ 時最小化到背景

開啟後按視窗 ✕ 不會結束，只藏到背景；只要上方「彈跳訊息提醒」有開，仍會跳出訊息框。可從系統匣還原，或下方結束程式。

Little Reply（開發者）

先啟用 Google Chat API。加入「Little Reply」後再在小工具內按「授權使用」即可，不必登入時一次授權全部功能。

Google 試算表（開發者）

正式版已綁死讀取 9527。此區僅 npm start 開發模式可見。

Google Sites 瀏覽紀錄

資料寫入試算表分頁「瀏覽紀錄」（不是其他分頁）。App 顯示以該分頁同步為準；若人數對不上請按「清除本機瀏覽快取並重同步」。

  1. 加入專案時請貼 編輯網址的 /d/ Site ID（不要只貼 …/duck815?usp=sharing）。
  2. 按「複製 Apps Script」→ 貼到 script.google.com。貼上後請確認開頭有一行 var LOG_SHEET_ID = '一長串ID'，不可是 PASTE_SPREADSHEET_ID。若是，按「複製紀錄試算表 ID」手動改進去。
  3. 部署 → 新增部署 → 網頁應用程式。
    執行身分：我；誰可以存取：網域內的所有人。
  4. 複製網址，必須長得像：https://script.google.com/macros/s/XXXX/exec。
    ❌ 不要用 Drive、試算表、script 編輯器、或 /dev 網址。
  5. 把該網址貼回上方「部署網址」並儲存；用「複製嵌入網址」嵌進 Site（插入→嵌入→網址）。
  6. 發布後用同仁帳號開新分頁測：若嵌入區顯示「追蹤就緒」才算成功。超連結請用「複製轉址範例」（url 已 encode）。
  7. 改過程式後一定要：管理部署 → 編輯 → 新版本。
